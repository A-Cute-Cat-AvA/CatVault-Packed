# 🐱 CatVault

> 一款纯本地、零网络依赖的离线密码管理器。
> 你的密码，只属于你自己。

---

## ✨ 为什么选择 CatVault？

- 🔒 **军事级加密**：采用 Argon2id + AES-256-GCM，即使 U 盘丢失，别人也无法破解
- 📦 **完全离线**：不依赖任何云服务，数据 100% 掌握在你自己手里
- 💾 **U 盘便携**：整个文件夹拷进 U 盘，插上任意电脑即插即用
- ☁️ **可选云备份**：支持备份到自己的 Gitee 仓库（已加密，安全）
- 🐱 **开源免费**：源码公开，无广告，无追踪

## 🚀 快速开始

### 第一步：下载

在本页面的 **Releases** 中下载最新版本的 `CatVault-Packed.zip`，解压到任意文件夹（推荐直接放在 U 盘里）。

### 第二步：运行

双击 `CatVault.exe`，程序会自动创建密码库。

### 第三步：设置主密码

**首次运行时，程序会要求你输入一个主密码。这个密码是解锁所有密码的唯一钥匙。**

⚠️ **请务必牢记它！一旦忘记，任何人都无法帮你找回。**

建议使用一句你自己记得住的短语，比如：
`woyaochixiangjiaoniuroufen2026!`

## 📖 常用命令

启动后，会出现 `>>>` 提示符。输入以下命令使用：

### 密码管理

| 命令 | 作用 |
| :--- | :--- |
| `add <名称> <备注> <密码>` | 新增一条密码 |
| `add <名称> <密码>` | 新增一条无备注的密码 |
| `show <名称>` | 查看某条密码 |
| `update <名称> <备注> <密码>` | 修改一条密码 |
| `delete <名称>` | 删除一条密码（需输入 YES 确认） |
| `list` | 列出所有条目 |
| `search <关键词>` | 搜索条目 |

**示例：**
add 淘宝 购物账号 MyPwd123!
show 淘宝
名称：淘宝
备注：购物账号
密码：MyPwd123!

text

### 系统命令

| 命令 | 作用 |
| :--- | :--- |
| `help` | 显示帮助 |
| `clear` | 清屏 |
| `passwd` | 修改主密码 |
| `reset` | 恢复出厂设置（⚠️ 清空所有数据） |
| `exit` / `quit` | 退出程序 |

### 云备份命令（可选）

想开启云备份，请参考 [详细教程](链接到你的文档)。

| 命令 | 作用 |
| :--- | :--- |
| `cloud true` | 开启自动云备份（退出时自动上传） |
| `cloud false` | 关闭自动云备份 |
| `cloud backup gitee` | 手动上传到 Gitee 仓库 |
| `cloud restore gitee` | 从 Gitee 仓库恢复 |
| `cloud status` | 查看备份状态 |

## 🔒 安全说明

1. **所有数据在上传前已加密**，即使云仓库是公开的，别人看到的也只是一堆乱码。
2. **主密码永不离开你的电脑**，CatVault 不会把它发送到任何地方。
3. **主密码一旦遗忘，数据将无法恢复**，请务必牢记并做好备份。

## ❓ 常见问题

**Q：我把 U 盘弄丢了，密码会不会泄露？**
A：不会。所有 `.dat` 文件都是加密的，没有主密码，别人无法读取内容。

**Q：怎么备份我的密码库？**
A：直接复制 `Password/` 文件夹到别处。或者开启云备份（`cloud true`），程序退出时会自动上传到你的 Gitee 仓库。

**Q：换电脑了怎么办？**
A：把整个 `CatVault-Packed` 文件夹拷到新电脑（或 U 盘），运行 `CatVault.exe`，输入主密码即可。

**Q：可以在 Mac / Linux 上用吗？**
A：目前仅支持 Windows。Mac / Linux 用户可从源码运行（见[源码仓库](链接)）。
